# Sitio web de la Iglesia Bautista Eliacim

Sitio informativo para una iglesia: presenta la comunidad, sus servicios y ministerios, sermones, eventos y una página de donaciones. Es la parte pública; la administración de finanzas de la iglesia es un proyecto aparte y no está en este repositorio.

## Páginas

- **Inicio:** portada, servicios, ministerios y llamada a la acción.
- **Nosotros**, **Sermones**, **Eventos** y **Donaciones**.

## Stack

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4 y lucide-react.

## Cómo correrlo

```bash
npm install
npm run dev   # http://localhost:3000
```

## Estado

Maqueta de contenido y diseño. Los datos de contacto del pie de página son de ejemplo y las páginas de sermones y eventos aún no se alimentan de una fuente de datos.
